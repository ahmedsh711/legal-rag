The business problemالمشكلة اللي بنحلها

A law firm or a government office needs to answer questions about Egyptian civil law quickly and with citations: "Article 147 says…". A wrong answer that sounds confident is worse than no answer, because a lawyer may act on it. So the system must:

  • find the right articles (retrieval),
  • write an answer only from those articles (grounded generation),
  • cite article numbers a lawyer can check,
  • say "I can't find this in the code" instead of guessing,
  • and keep doing this reliably in production: measured, versioned, monitored.

The last point is what this course is about. The model is a small part; the system around it is the job.

مكتب محاماة أو جهة حكومية محتاجة تجاوب على أسئلة في القانون المدني المصري بسرعة وبالاستشهاد بالمادة: "المادة 147 بتقول…". الإجابة الغلط اللي شكلها واثقة أخطر من إن مفيش إجابة، لأن المحامي ممكن يتصرف على أساسها. عشان كده النظام لازم:

  • يلاقي المواد الصح (Retrieval)،
  • يكتب الإجابة من المواد دي بس (Grounded generation)،
  • يذكر رقم المادة عشان المحامي يراجعها،
  • يقول "مش لاقي ده في القانون" بدل ما يألّف،
  • ويفضل شغال كده في الـ production: متقاس، ومتسجّل له versions، ومتراقب.

النقطة الأخيرة دي هي الكورس كله. الموديل حتة صغيرة؛ الشغل الحقيقي هو السيستم اللي حواليه.

Offline paths (run on a schedule or on change):

  • Corpus: PDF → parse → articles.json → embed → Qdrant collection. Versioned with DVC.
  • Evaluation: golden questions → RAGAS + judge → MLflow run → best config registered as production.
  • Release: PR → CI (lint, tests, quality gate) → image on Docker Hub → canary → full rollout.
  • Watching: Prometheus metrics, Langfuse traces, Evidently drift → alerts → Airflow → re-index / re-evaluate → human approval.

المسارات الأوفلاين (بتشتغل بجدول مواعيد أو لما حاجة تتغير):

  • الداتا: PDF ← parse ← articles.json ← embeddings ← collection في Qdrant. وكله متسجّل بـ DVC.
  • التقييم: أسئلة ذهبية ← RAGAS وjudge ← run في MLflow ← أحسن config بيتسجل باسم production.
  • النزول للـ production: PR ← CI (lint وtests وquality gate) ← image على Docker Hub ← canary ← rollout كامل.
  • المراقبة: metrics في Prometheus، traces في Langfuse، drift من Evidently ← alerts ← Airflow ← نعمل re-index أو نقيّم تاني ← وبشر يوافق في الآخر.

Glossaryقاموس المصطلحات

TermMeaningيعني إيه
MLOpsPractices that take a model from a notebook to a reliable, monitored, repeatable production system.الممارسات اللي بتنقل الموديل من النوتبوك لسيستم شغال في الـ production، يتكرر ويتراقب.
LLMOpsMLOps for LLM apps: same ideas plus prompts, tokens, traces, judges and new kinds of drift.MLOps لتطبيقات الـ LLM: نفس الأفكار بالإضافة للـ prompts والـ tokens والـ traces والـ judges وأنواع drift جديدة.
RAGRetrieval-Augmented Generation: fetch relevant text first, then let the LLM answer from it.بنجيب النصوص اللي تخص السؤال الأول، وبعدين الـ LLM يجاوب منها مش من دماغه.
TokenThe unit an LLM reads and is billed in; a word is often 1–3 tokens, Arabic often more.الوحدة اللي الموديل بيقرا بيها وبتتحاسب بيها؛ الكلمة غالبًا 1–3 tokens، والعربي غالبًا أكتر.
EmbeddingA list of numbers (a vector) that represents meaning; similar meanings are close.ليستة أرقام (vector) بتمثل المعنى؛ المعاني القريبة بتبقى قريبة من بعض.
ChunkOne piece of the corpus that gets embedded and retrieved. Here: one article.حتة من الداتا بنعملها embedding ونرجّعها. عندنا: مادة واحدة.
Vector databaseA database that finds the nearest vectors to a query fast. We use Qdrant.داتابيز بتلاقي أقرب vectors للسؤال بسرعة. بنستخدم Qdrant.
Hybrid searchCombining meaning-based (dense) and keyword-based (sparse) search.بندمج البحث بالمعنى (dense) مع البحث بالكلمات (sparse).
RerankerA second, more careful pass that reorders the retrieved candidates.مرحلة تانية أدق بترتب النتايج اللي رجعت من جديد.
JevA hosted "decision model": it answers typed questions (yes/no, choice, score) with probabilities, never free text."موديل قرارات" على السحابة: بيجاوب أسئلة محددة (آه/لأ، اختيار، درجة) باحتمالات، ومبيكتبش كلام حر.
Grounded / faithfulEvery claim in the answer is supported by the retrieved text.كل جملة في الإجابة ليها دليل في النص اللي رجعناه.
HallucinationA fluent, confident statement the sources do not support.كلام واثق وشكله صح بس ملوش أصل في المصادر.
Golden setA frozen, versioned list of test questions with expected articles/answers.ليستة أسئلة اختبار ثابتة ومتسجّلة، معاها المواد والإجابات المتوقعة.
RAGASA library that scores RAG answers: faithfulness, relevancy, context precision and recall.مكتبة بتدي درجات لإجابات الـ RAG: الأمانة للمصدر، والصلة بالسؤال، ودقة وشمول السياق.
LLM-as-a-judgeUsing an LLM with a written rubric to grade outputs. Must be calibrated against humans.بنستخدم LLM ومعاه معايير مكتوبة عشان يقيّم. لازم نعايره قصاد تقييم بشري.
MLflowTracks experiments (params, metrics, artifacts) and holds a registry of versions.بيسجّل التجارب (params وmetrics وartifacts) وفيه registry للـ versions.
DVCGit for data: Git keeps a small pointer file, the bytes live in remote storage.Git للداتا: Git بيحفظ فايل صغير بيشاور، والداتا نفسها في storage بره.
CI / CD / CTContinuous integration (check every change), delivery/deployment (ship it), training (re-evaluate/re-build on triggers).CI بيشيك كل تغيير، CD بينزّله، CT بيعيد التدريب أو التقييم لما يحصل trigger.
p95 latency95% of requests are faster than this. The average hides slow users; p95/p99 don't.95% من الطلبات أسرع من الرقم ده. المتوسط بيخبي المستخدمين اللي اتأخروا؛ p95 وp99 لأ.
TTFTTime to first token: how long until the user sees the answer start.الوقت لحد أول token: قد إيه المستخدم بيستنى لحد ما الإجابة تبدأ تظهر.
CanarySend a small % of traffic to the new version, watch it, then grow or roll back.بنبعت نسبة صغيرة من الترافيك للنسخة الجديدة، نراقبها، وبعدين نكبّر أو نرجع.
DriftThe world (questions, documents, models) changes so quality drops without any error.الدنيا بتتغير (الأسئلة، المستندات، الموديلات) فالجودة بتقل من غير أي error.
Trace / spanA trace is one request's full story; spans are its timed steps (retrieve, rerank, generate…).الـ trace هو حكاية الطلب كله؛ والـ spans هي خطواته بوقت كل واحدة.
GuardrailA check before or after the model (PII, prompt injection, off-topic, groundedness).فحص قبل أو بعد الموديل (بيانات شخصية، prompt injection، خارج الموضوع، الأمانة للمصدر).
Quantization (AWQ)Storing weights in fewer bits (4-bit) so a model fits a small GPU, at some quality cost.بنخزن الأوزان بعدد bits أقل (4-bit) عشان الموديل يدخل GPU صغير، مع شوية خسارة في الجودة.
